# Visual Studio Code (VS Code)

## 1. Introduction

Visual Studio Code, commonly called **VS Code**, is a free and lightweight source-code editor developed by Microsoft.

It is used by developers to write, edit, debug and manage code for different programming languages and technologies.

VS Code supports languages such as:

* HTML
* CSS
* JavaScript
* C++
* Java
* Python
* SQL
* PHP
* Node.js

It can also be used with Git and GitHub/GitLab for version control and software development.

---

## 2. What is VS Code?

**Visual Studio Code is a source-code editor that provides tools for writing, editing, debugging and managing software projects.**

It is available for Windows, macOS and Linux.

VS Code is popular because it is:

* Free
* Lightweight
* Fast
* Easy to use
* Customizable
* Supports many programming languages
* Supports Git and version control
* Provides extensions for additional features

---

## 3. Features of VS Code

### 3.1 Code Editor

VS Code provides an editor where programmers can write and modify source code.

It provides features such as:

* Syntax highlighting
* Auto-completion
* Code formatting
* Error detection
* Code navigation

---

### 3.2 Syntax Highlighting

VS Code displays different parts of code in different styles.

For example, keywords, functions, strings and variables can be easily identified.

This makes the code easier to read and understand.

---

### 3.3 IntelliSense

**IntelliSense** provides smart code suggestions while writing code.

For example, when writing JavaScript, VS Code can suggest:

* Variables
* Functions
* Methods
* Properties
* Parameters

This helps developers write code faster and reduces mistakes.

---

### 3.4 Extensions

Extensions add extra features and functionality to VS Code.

For example:

* Live Server
* Prettier
* GitLens
* Python
* C/C++
* Java Extension Pack

Extensions can be installed from the VS Code Extensions Marketplace.

---

### 3.5 Integrated Terminal

VS Code provides a built-in terminal.

The terminal allows developers to execute commands without opening a separate command prompt.

For example:

```bash
git status
git add .
git commit -m "Initial commit"
git push
```

It can also be used to run programs and install packages.

---

### 3.6 Debugging

VS Code provides a built-in debugging system.

Debugging helps developers find and fix errors in their programs.

Important debugging features include:

* Breakpoints
* Step over
* Step into
* Step out
* Continue
* Variable inspection

---

### 3.7 Git Integration

VS Code has built-in support for Git.

Developers can perform Git operations directly from VS Code.

Common operations include:

* Initialize repository
* Stage changes
* Commit changes
* Create branches
* Switch branches
* Pull changes
* Push changes
* View changes

---

## 4. VS Code Interface

The main parts of the VS Code interface are:

### 4.1 Activity Bar

The Activity Bar is present on the left side.

It provides access to different sections such as:

* Explorer
* Search
* Source Control
* Run and Debug
* Extensions

---

### 4.2 Explorer

The Explorer displays the files and folders of the current project.

For example:

```text
my-project
│
├── index.html
├── style.css
├── script.js
└── images
```

It helps developers easily manage project files.

---

### 4.3 Editor

The Editor is the main area where code is written and modified.

Multiple files can be opened using tabs.

---

### 4.4 Search

The Search feature allows developers to find specific words or code inside files.

It is useful when working on large projects.

---

### 4.5 Source Control

The Source Control section provides Git-related functionality.

It shows:

* Modified files
* New files
* Deleted files
* Staged changes

Developers can commit and manage changes from this section.

---

### 4.6 Run and Debug

The Run and Debug section is used to run programs and debug them.

It allows developers to set breakpoints and execute programs step by step.

---

### 4.7 Extensions

The Extensions section is used to search, install, update and manage VS Code extensions.

---

### 4.8 Terminal

The integrated terminal appears at the bottom of VS Code.

It can be used to execute commands such as:

```bash
git status
npm install
npm start
python app.py
```

---

## 5. How to Install VS Code

Basic installation steps are:

1. Download VS Code from the official Visual Studio Code website.
2. Run the installer.
3. Follow the installation instructions.
4. Complete the installation.
5. Open VS Code.

After installation, a project folder can be opened in VS Code.

---

## 6. Creating a Project in VS Code

To create a project:

1. Open VS Code.
2. Select **File → Open Folder**.
3. Create or select a project folder.
4. Open the folder.
5. Create required files.
6. Write the code.
7. Save the files.
8. Run and test the project.

Example:

```text
WebProject
│
├── index.html
├── style.css
└── script.js
```


The repository can then be managed using Git commands or the VS Code interface.

## 14. VS Code Debugging

Debugging means finding and fixing errors in a program.

VS Code provides debugging tools that help developers understand how their program is executing.

Important debugging concepts are:

### Breakpoint

A breakpoint temporarily stops program execution at a particular line.

### Step Over

Executes the current line and moves to the next line.

### Step Into

Enters inside a function to understand its execution.

### Step Out

Exits from the current function.

### Continue

Continues program execution until the next breakpoint.

Debugging helps identify logical and runtime errors.

## 20. VS Code vs Visual Studio

VS Code and Visual Studio are different products.

| VS Code                                | Visual Studio                                                   |
| -------------------------------------- | --------------------------------------------------------------- |
| Lightweight code editor                | Full-featured IDE                                               |
| Faster and smaller                     | Larger application                                              |
| Highly extension-based                 | Many features built-in                                          |
| Supports many languages                | Strong support for .NET and other technologies                  |
| Free                                   | Community edition is free; other editions may require licensing |
| Suitable for many types of development | Suitable for large and complex application development          |

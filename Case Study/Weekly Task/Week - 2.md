# Week 2 - GitHub

## Objective

To understand GitHub and learn how to create, manage and
collaborate on repositories using GitHub.

## What is GitHub?

GitHub is a cloud-based platform that provides hosting for
Git repositories. It helps developers store, manage and
collaborate on projects.

## Important GitHub Features

- Repository
- README file
- Branches
- Commits
- Pull Requests
- Issues
- Collaboration

## GitHub and Git

Git is used for version control on a local computer,
while GitHub is used to host Git repositories online and
collaborate with other developers.

## Basic GitHub Workflow

Local Repository → Commit → Push → GitHub Repository

## Important Commands

```bash
git clone <repository-url>
git add .
git commit -m "message"
git push
git pull
git branch
git switch
```

## Practical Work

1. Created a GitHub repository.
2. Connected a local Git repository with GitHub.
3. Added and committed project files.
4. Pushed changes to GitHub.
5. Cloned a GitHub repository.
6. Created and worked with branches.
7. Learned the basic concept of Pull Requests.

## Learning Outcome

Learned how GitHub is used to host Git repositories,
manage project files, track changes and collaborate with
other developers.

## Conclusion

GitHub provides an online platform for managing Git
repositories and collaborating on software projects.
It is widely used in modern DevOps workflows.

# Week 3 - GitLab

## Objective

To understand GitLab and learn how to create, manage and
collaborate on Git repositories using GitLab.

## What is GitLab?

GitLab is a web-based DevOps platform that provides Git
repository hosting and tools for software development,
collaboration, and CI/CD.

## Important GitLab Features

- Git Repository
- Projects
- Branches
- Commits
- Merge Requests
- Issues
- Collaboration
- CI/CD

## Git and GitLab

Git is a version control system used to track changes locally,
while GitLab provides an online platform to host Git repositories
and collaborate with team members.

## Basic GitLab Workflow

Local Repository → Commit → Push → GitLab Repository

## Important Commands

```bash
git clone <repository-url>
git add .
git commit -m "message"
git push
git pull
git branch
git switch
```

## Practical Work

1. Created a project/repository on GitLab.
2. Connected a local Git repository with GitLab.
3. Added and committed files.
4. Pushed changes to GitLab.
5. Cloned a GitLab repository.
6. Created and worked with branches.
7. Learned the concept of Merge Requests.

## GitLab vs GitHub

| GitLab | GitHub |
|--------|--------|
| DevOps and CI/CD focused | Collaboration and code hosting focused |
| Provides built-in CI/CD | Provides GitHub Actions |
| Uses Merge Requests | Uses Pull Requests |
| Hosts Git repositories | Hosts Git repositories |

## Learning Outcome

Learned how GitLab is used to host repositories, manage
branches, track changes, and collaborate with team members.

## Conclusion

GitLab is an important DevOps platform that provides Git
repository management, collaboration, and CI/CD capabilities.

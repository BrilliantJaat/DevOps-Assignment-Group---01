# Week 4 - Visual Studio Code (VS Code)

## Objective

To understand Visual Studio Code and learn how to use its built-in Git features for managing projects and collaborating with GitHub and GitLab.

## What is VS Code?

Visual Studio Code is a free code editor developed by Microsoft. It supports multiple programming languages and provides tools for writing, editing, debugging, and managing code.

## Important Features of VS Code

* Code Editor
* Integrated Terminal
* Extensions
* Source Control
* Git Integration
* Debugging
* IntelliSense

## VS Code and Git

VS Code provides built-in Git support that allows developers to track changes, stage files, commit updates, and manage branches directly from the editor.

## Important Components

1. **Explorer:** Displays project files and folders.
2. **Source Control:** Shows modified files and Git changes.
3. **Terminal:** Runs Git commands inside VS Code.
4. **Extensions:** Adds extra features and tools.
5. **Command Palette:** Provides quick access to editor commands.

## Practical Work

1. Installed and opened Visual Studio Code.
2. Created and opened a project folder.
3. Opened the integrated terminal.
4. Initialized a Git repository.
5. Created and modified project files.
6. Used Source Control to view changes.
7. Staged and committed files.
8. Learned how to connect a project with GitHub or GitLab.

## Git Commands in VS Code

```bash
git --version
git init
git status
git add .
git commit -m "Updated project"
git branch
git pull
git push
```

## VS Code Git Workflow

Open Project → Initialize Repository → Modify Files → Stage Changes → Commit → Push

## Advantages of VS Code

* Easy-to-use interface.
* Supports many programming languages.
* Built-in terminal and Git integration.
* Useful extensions for development.
* Simplifies project management and collaboration.

## Learning Outcome

After completing Week 4, I learned how to use VS Code for coding, manage files, run Git commands, track changes, and work with Git repositories.

## Conclusion

VS Code is a useful development tool that simplifies coding and Git operations. Its integration with GitHub and GitLab helps developers manage projects and collaborate efficiently.
